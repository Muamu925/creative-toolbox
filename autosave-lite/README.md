# Autosave Lite

原生 macOS 菜单栏工具，提供空闲时请求保存与崩溃后的恢复资料保留。当前源码版本为 **0.1.2**。

## 使用方式

1. 将 `Autosave Lite.app` 放入「应用程序」并打开。关闭设置窗口后，程序继续在菜单栏运行；选择菜单栏中的「退出 Autosave Lite」才会结束。
2. 点击「添加应用」，选择正在运行的程序，或手动选择 `.app`。首次默认选择本机已安装的 Illustrator、Photoshop。应用选择不需要辅助功能或输入监控权限。
3. 每次启动目标软件，会询问是否启用本次保护。选择「本次不启用」后，本次运行不会发送保存请求；下次启动重新询问。也可从菜单栏重新确认或结束本次保护。
4. 在系统设置中为「应用程序」中的 Autosave Lite 开启辅助功能和输入监控。返回后点击「重新检查」可查看当前进程的权限。若两项可用但事件发送未生效，点击「事件发送…」并按系统提示操作。若设置已打开但应用内仍未生效，从菜单栏退出 Autosave Lite 后重新打开。更新后仍未生效时，可在对应系统设置页移除旧条目，再添加当前安装版。
5. 新文档先手动保存一次，确定名称和位置。默认最短间隔 **60 秒**、连续空闲 **3 秒**。可选择 30 秒／1 分钟／2 分钟／5 分钟，以及空闲 3／5／10 秒。
6. **「登录 Mac 后自动启动」默认关闭**。仅在您主动勾选时注册登录项；取消勾选即请求取消注册。系统若要求批准，界面将显示待批准状态，并提供系统设置入口。登录启动需先将应用放在 `/Applications` 中。

本分支提供源码和构建脚本。本机已验证 Apple Silicon 构建，采用本地临时签名，尚未经过 Apple 公证。版本验证环境和剩余验收见 [验证记录](VALIDATION.md)。

## 自动保存如何判断空闲

最短间隔达到后，只有同时满足以下条件才会发送一次 ⌘S：

- 本次应用会话已明确同意，应用仍在前台，且文档保持稳定达到所选空闲时间。
- 辅助功能、输入监控、事件发送均可用；系统处于活动桌面，未开启安全输入。
- 所有键盘按键和鼠标按钮已松开，最近连续 3／5／10 秒没有键鼠输入。
- 当前不是模态对话框、保存面板、输入框或菜单；可以识别已有且可写的本地文档。
- 本轮存在新的候选操作，或者首次检查该文档；若原应用明确报告文档未修改，则不发送。

鼠标移动会延后请求，但不会独自触发下一轮保存。持续空闲时不重复发送。输入事件计数只是候选操作信号，不等于确认内容发生改变。工具使用系统输入时间与事件计数，不记录输入文字或键盘内容。

发送前再次核对会话、窗口、文档、权限和输入状态。切换应用、关闭应用、暂停检测或更改选择会使待发请求失效；睡眠和锁屏后重新开始计时，不补发积压请求。保存请求不切换到后台应用，不批量保存多个文档。

**「已发送 ⌘S」只表示快捷键请求已提交，不表示文件已写入成功。** 原应用保存完成、磁盘文件变化以及重新打开后的内容需另外核验。无法识别文档位置时会显示具体原因并等待，不盲目发送。0.1.0 曾在本机 Illustrator 与 Photoshop 的普通本地测试文档中分别确认写盘和重开后的内容。0.1.2 调整了授权检查，该版本的宿主写盘仍待重新验收。

如仍运行旧工具箱，请确保同一目标软件只启用一处自动保存，以免重复发送。

## 崩溃抢救

菜单栏或设置窗口中的「崩溃抢救」提供以下流程：

1. **保留资料**：检查 Illustrator 的 `DataRecovery` 或 Photoshop 的 `AutoRecover`，将普通文件按原目录结构复制至新的独立快照。也可手动选择其他恢复目录或原设计文件。每个文件记录大小和 SHA-256，保留来源、时间及异常记录。
2. **原应用恢复**：保留后打开原应用，使用其自身的恢复机制。工具不会回写恢复目录，不会将 `.aishm` 改名为 `.ai`，不会自动点击恢复或覆盖确认。
3. **另存并记录**：在原应用中另存为新文件，等待保存完成，再用「记录另存文件」记录路径和校验信息。本工具不修改所选文件。
4. **内容确认**：重新打开另存文件，检查所需修改，再点击「确认内容已恢复」。只有用户明确确认且文件校验一致，记录才进入「内容已确认」。

可选择「所选应用退出后，自动保留遗留恢复数据」，首版默认开启，暂停整个检测或退出工具后停止自动保留。该选项适用于已选择的 Illustrator、Photoshop，不需要该会话同意发送快捷键。正常退出也可能遗留资料，因此记录只说明应用已退出，**不把退出自动判定为崩溃**。

自动检查的默认目录覆盖多个 Adobe 版本及 Illustrator 语言目录。更改过软件恢复位置时，请使用手动选择。系统临时目录通过 macOS 的 `FileManager.temporaryDirectory` 自动读取，可在窗口查看、复制路径并直接打开；该入口不会自动复制整个临时目录或把普通缓存认定为可恢复文档。[Apple 接口说明](https://developer.apple.com/documentation/foundation/filemanager/temporarydirectory)

快照保留普通文件及嵌套文件路径；符号链接跳过并标记异常，空目录不作为可恢复数据。源文件正在变化、读取失败或结构变化时标记「快照需检查」。副本校验通过仅说明复制时的字节一致，不能保证多文件处于同一原子时刻，也不能证明原应用可成功恢复。

单次快照上限 2 GiB、20,000 个文件，快照目录总量上限 5 GiB；达到上限时停止并说明原因，不自动删除旧快照。可将后续快照改存外置磁盘，已有快照不会自动移动。快照对已经不存在的数据无能为力；本工具不提供已删除扇区扫描、历史版本或云备份。

## 数据与隐私

- 独立数据目录：`~/Library/Application Support/AutosaveLite/`。
- 设置：`settings.json`；默认快照：`Rescue/`；单实例锁：`instance.lock`。
- 每次启动的同意仅保存在内存，退出目标应用或工具后失效。
- 快照清单包含来源路径、文件摘要、另存文件路径和确认结果；文件和清单只存于本机选定位置。
- 应用不联网，不上传设计文件，不读取键盘输入内容，不修改 Adobe 的恢复资料或工作区配置。
- 开机自启的实际状态来自 macOS 登录项，不从设置文件推断成功。

## 从源码构建

需要 macOS、Python 3 和带配套 SDK 的 Swift 命令行工具。无需安装第三方运行时或切换系统开发工具路径。

```sh
python3 autosave-lite/scripts/build.py --test
python3 autosave-lite/scripts/build.py
python3 autosave-lite/scripts/build.py --package
# 对已验收的安装版仅打包，保留其签名与授权身份：
python3 autosave-lite/scripts/build.py --package-only --app "/Applications/Autosave Lite.app"
```

从仓库根目录执行。构建脚本自动选择与当前 Swift 编译器匹配的已安装 SDK；必要时可用 `AUTOSAVE_SDK` 指定。构建本机架构，最低部署声明 macOS 13；这不代表 macOS 13 或 Intel 已实际验收。

- 应用：`dist/Autosave Lite.app`
- 安装镜像：`dist/AutosaveLite-0.1.2-macOS-arm64-unsigned.dmg`
- 源码：`dist/AutosaveLite-0.1.2-source.zip`
- 本地测试输出：`artifacts/autosave-lite/`

开发用 `--smoke-dir <目录>` 仅生成隔离设置和原生窗口截图，不发送快捷键、不注册登录项。`--inspect-frontmost <JSON 文件>` 只检查当前前台窗口和权限，不保存用户窗口标题或文档路径，不发送按键；需要在可用的桌面会话内运行。

保存流程、恢复资料处理和后续验证重点见[设计与实现](../docs/AUTOSAVE_LITE_PLAN.md)。
