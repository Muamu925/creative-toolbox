# 创作工具箱：综合功能地图

更新：2026-09-18。产品方向：面向设计、剪辑、三维与音乐创作，把跨软件的常用辅助任务集中在一个本地桌面工具箱中。当前 0.4.0 是早期预览版；“综合”描述发展方向，不表示已经实现所有模块。

后续实施顺序以 [整体架构与发展方案](ARCHITECTURE_PLAN.md) 为准。本文保留候选功能地图；专项方案补充具体交互，不各自承诺另一套版本顺序。

## 已实现的基础

| 模块 | 当前能力 | 实际边界 |
| --- | --- | --- |
| 首页与工具入口 | 工具搜索、收藏、最近使用、字体与配色统一入口、按需页面、保护适配故障降级 | 尚无图片素材库或项目管理 |
| 创作保护 | 按应用配置保存快捷键、输入空闲与最短间隔；观察、提醒和自动模式 | 每次启动默认观察；快捷键发送不能确认保存结果，也不能普遍识别录音、MIDI、渲染和首次保存 |
| 字体与文字 | 本机字体搜索、分组、标签、收藏、备注、JSON 备份、2–4 栏真实样式对照 | 无字体安装、字形覆盖检查或授权判断 |
| 尺寸与节奏 | 毫米 / 像素 / PPI、等比缩放、BPM 音符时长 | 仅计算；BPM 以四分音符计，未连接宿主传输状态 |
| 色彩与对比度 | 色板、悬浮色卡、收藏排序、20 步会话撤销、图片提色、文字对比度、JSON / CSS / PNG 输出 | 不透明 sRGB；图片主色为近似结果；无 CMYK / 专色校样 |

81 项现有测试覆盖保存策略、字体整理、配色状态和导出、界面同步、换算与新工具入口。Windows 有本地启动检查；macOS 有自动构建和测试，真机安装、权限与宿主交互仍待验证。

## 功能地图：按创作任务组织

下表均为候选功能，尚未实现。优先级是产品判断，需由真实使用反馈修正。

| 方向 | 可以解决的小任务 | 第一版范围 | 后续扩展 |
| --- | --- | --- | --- |
| 工具入口 | 想算一个数或处理一个文件，却找不到入口 | 在现有搜索、收藏与最近使用上增加按场景筛选 | 可配置全局唤起、按前台应用建议工具 |
| 个人资料 | 收下参考素材，并在下一次创作时找回 | PNG / JPEG 收集箱、集合、标签、来源、复制托管、去重与完整备份 | 链接大文件、浏览器收集、更多格式与相似搜索 |
| 灵感与参考 | 在编辑器旁持续查看构图、材质或分镜 | 从素材库打开大图、单图置顶、关联提色 | 多图参考板、拖动缩放、备注、截图标注与参考图对比 |
| 项目规格 | 开工和交付时反复查尺寸、帧率、BPM 与要求 | 项目名称、目录入口、可选规格、素材 / 字体 / 色板引用和说明导出 | 关联参考板与更完整的交付流程 |
| 文件整理 | 给海报、渲染序列或音频分轨统一名称 | 前后缀、替换、序号、变更预览、冲突检查、撤销清单 | 目录模板、按摘要查重报告、交付清单 |
| 图像交付 | 输出所需尺寸并整理给别人 | 单一长边等比缩放、保留支持的原格式、简单防冲突命名、新输出目录、进度和取消 | 多规格与格式转换、自定义命名、联系表、目标体积试算、透明度与色彩配置检查 |
| 字体与文案 | 比较排版并整理从不同地方复制的文字 | 未安装字体目录、智能分组、字数统计、空格 / 换行整理预览 | 字号阶梯、字形覆盖、常用文本片段、样张导出 |
| 视频与动效 | 看素材规格，计算帧数，抽取参考帧 | ffprobe 信息查看、整数帧率时码换算、单帧导出 | 接触表、代理、音轨提取、明确关键帧边界的切段 |
| 音乐与声音 | 快速估算速度、段落时长和声音参数 | Tap Tempo、小节时长、音高↔频率、自定义基准音 | 音频元信息、试听、响度分析、分轨规格检查 |
| 三维与材质 | 整理贴图与渲染输出，发现规格不一致 | 复用文件命名、图片尺寸与序列完整性报告 | 贴图通道打包、UDIM 检查、单位换算；专有工程适配另行开发 |
| 创作保护 | 知道为什么没有保存、出问题时有迹可查 | 优化规则解释、暂停入口、最近触发结果 | 可信宿主保存回执、用户指定文件的版本副本 |
| 日常效率 | 复用短文本、记录工作时长、生成交付链接入口 | 文本片段、可选计时、二维码等独立小工具 | 显式开启的剪贴板历史、操作配方 |

取舍原则：功能应有具体输入、可检查结果，并能用于真实创作任务。一个工具可以跨领域复用，例如统一命名同样服务于平面交付、视频素材和音乐分轨。

## 推荐开发顺序

### A：入口与基础整理（0.4.0 第一版已完成）

首页负责继续工作与常用入口；工具页提供完整目录、搜索和收藏。现有页面按需加载，创作保护的系统能力故障不阻止字体、配色等功能启动。记录性能与数据恢复基线，保留独立使用各工具的方式。

### B：个人资料积累

先完成图片收集、复制托管、待整理、集合 / 标签 / 来源、查找、单图置顶、关联提色与完整备份。资源稳定 ID、可恢复导入和后台任务随这条流程落地。自由参考画板不作为收集功能的前置条件。

### C：项目组合与交付

项目规格卡关联素材、配色和字体，明确共享引用与项目副本；导出基础说明后，再接入一种图片输出流程。多图参考板、批量重命名与媒体处理分别作为后续小版本候选。

### 后续：按创作任务增加能力

视频从元信息与抽帧开始，音乐先增加 Tap Tempo、小节与频率计算；纯计算可以穿插小步交付。未安装字体目录、媒体引擎和系统激活各有独立边界。引擎可用性、分发方案、许可与安装包体积在集成时核实。

这些阶段不是版本号或发布日期承诺。用户反馈可能调整范围；macOS 真机验证与现有问题修复贯穿各阶段。

## 可以形成的三条完整流程

- **设计**：打开参考图 → 对照字体 → 计算输出尺寸 → 多尺寸导出 → 统一命名。
- **视频**：查看素材规格 → 记录项目帧率 → 抽取分镜帧 → 生成联系表 → 整理交付文件。
- **音乐**：Tap Tempo → 计算段落与延迟时长 → 记录工程规格 → 检查分轨信息 → 统一命名。

当前只实现其中的字体、尺寸、BPM 音符换算、色彩与保存辅助；流程中的其他步骤为规划。

## 共享架构

继续使用 **Python + PySide6**，按目标系统分别构建 Windows 和 macOS 包。

- **应用外壳**：导航、工具搜索、收藏、最近使用、窗口管理；首次打开不要求建项目。
- **内置工具注册表**：稳定 ID、名称、分类、关键词、页面工厂、输入 / 输出能力。已有页面逐个接入。
- **项目与资源服务**：规格字段、目录入口、托管参考图、资源引用；无需依赖 Photoshop、Cubase 等宿主的工程格式。
- **任务与文件服务**：预览、冲突检查、独立输出、进度、取消、失败重试、操作记录；供图片和媒体处理共享。
- **平台适配层**：前台窗口、输入空闲、快捷键、屏幕能力与系统权限；保留 Ctrl / Command 和用户自定义规则。
- **具体工具模块**：参考、文字、色彩、换算、文件、媒体、创作保护，各自保留领域逻辑与测试。

现有代码以 `ui.py` 为主窗口，`design_ui.py` 提供工具页面，`design_core.py` 提供配色与计算，PaletteModel 共享主面板和悬浮状态。内置工具注册表与按需页面已实现；项目服务、跨模块资源服务和通用任务队列尚未实现。入口使用与验证见 [工作台说明](WORKSPACE.md)。

架构、数据迁移与阶段验收见 [整体架构与发展方案](ARCHITECTURE_PLAN.md)；其他工具的交互草案见 [专项功能方案](NEXT_STAGE_SPEC.md)。
