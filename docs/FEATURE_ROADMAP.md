# 创作工具箱：综合功能地图

更新：2026-09-13。产品方向：面向设计、剪辑、三维与音乐创作，把跨软件的常用辅助任务集中在一个本地桌面工具箱中。当前 0.2.0 是早期预览版；“综合”描述发展方向，不表示已经实现所有模块。

## 已实现的基础

| 模块 | 0.2.0 能力 | 实际边界 |
| --- | --- | --- |
| 创作保护 | 按应用配置保存快捷键、输入空闲与最短间隔；观察、提醒和自动模式 | 每次启动默认观察；快捷键发送不能确认保存结果，也不能普遍识别录音、MIDI、渲染和首次保存 |
| 字体与文字 | 本机双字体对照、自定义文案、字号与粗体、复制字体名 | 无字体安装、字形覆盖检查或授权判断 |
| 尺寸与节奏 | 毫米 / 像素 / PPI、等比缩放、BPM 音符时长 | 仅计算；BPM 以四分音符计，未连接宿主传输状态 |
| 色彩与对比度 | 色板、悬浮色卡、收藏排序、20 步会话撤销、图片提色、文字对比度、JSON / CSS / PNG 输出 | 不透明 sRGB；图片主色为近似结果；无 CMYK / 专色校样 |

47 项现有测试覆盖保存策略、配色状态和导出、界面同步与换算。Windows 有本地启动检查；macOS 有自动构建和测试，真机安装、权限与宿主交互仍待验证。

## 功能地图：按创作任务组织

下表均为候选功能，尚未实现。优先级是产品判断，需由真实使用反馈修正。

| 方向 | 可以解决的小任务 | 第一版范围 | 后续扩展 |
| --- | --- | --- | --- |
| 工具入口 | 想算一个数或处理一个文件，却找不到入口 | 搜索、工具收藏、最近使用、按场景筛选 | 可配置全局唤起、按前台应用建议工具 |
| 灵感与参考 | 在编辑器旁持续查看构图、材质或分镜 | 本地参考图画板、拖动缩放、备注、单图置顶、保存恢复 | 截图标注、来源链接、参考图对比 |
| 项目规格 | 开工和交付时反复查尺寸、帧率、BPM 与要求 | 项目名称、目录入口、可选规格字段、工具收藏 | 关联参考板 / 字体 / 色板、规范页导出 |
| 文件整理 | 给海报、渲染序列或音频分轨统一名称 | 前后缀、替换、序号、变更预览、冲突检查、撤销清单 | 目录模板、按摘要查重报告、交付清单 |
| 图像交付 | 同一张图输出多个规格并整理给别人 | 批量等比缩放、格式转换、输出命名、独立输出目录、进度和取消 | 联系表、目标体积试算、透明度与色彩配置检查 |
| 字体与文案 | 比较排版并整理从不同地方复制的文字 | 字体收藏、常用样句、字数统计、空格 / 换行整理预览 | 字号阶梯、字形覆盖、常用文本片段、样张导出 |
| 视频与动效 | 看素材规格，计算帧数，抽取参考帧 | ffprobe 信息查看、整数帧率时码换算、单帧导出 | 接触表、代理、音轨提取、明确关键帧边界的切段 |
| 音乐与声音 | 快速估算速度、段落时长和声音参数 | Tap Tempo、小节时长、音高↔频率、自定义基准音 | 音频元信息、试听、响度分析、分轨规格检查 |
| 三维与材质 | 整理贴图与渲染输出，发现规格不一致 | 复用文件命名、图片尺寸与序列完整性报告 | 贴图通道打包、UDIM 检查、单位换算；专有工程适配另行开发 |
| 创作保护 | 知道为什么没有保存、出问题时有迹可查 | 优化规则解释、暂停入口、最近触发结果 | 可信宿主保存回执、用户指定文件的版本副本 |
| 日常效率 | 复用短文本、记录工作时长、生成交付链接入口 | 文本片段、可选计时、二维码等独立小工具 | 显式开启的剪贴板历史、操作配方 |

取舍原则：功能应有具体输入、可检查结果，并能用于真实创作任务。一个工具可以跨领域复用，例如统一命名同样服务于平面交付、视频素材和音乐分轨。

## 2026-09-14：字体管理优先细化

根据最新讨论，字体工作台作为下一步重点候选：先完成已安装字体的搜索、分组、标签、收藏和多栏比较，再扩展本地字体目录与系统激活。调研、范围、架构和验收见 [字体管理方案](FONT_MANAGER_SPEC.md)。以下原有阶段顺序作为其他模块的候选路线，后续以选定的开发范围为准。

## 推荐开发顺序

### 0.3 候选：工具更容易找到，参考资料更容易看

按可独立交付的顺序拆分，不要求一次做完：

1. **工具中心**：为已有模块提供搜索、收藏、最近使用；“设计 / 视频 / 音乐”只是筛选预设，用户可以改。
2. **参考图画板**：本地图片拖入、排列、备注、置顶与保存恢复。首要任务是参考图查看，提色作为可选动作。
3. **创作计算扩展**：Tap Tempo、小节时长、音高频率；整数帧率的帧数 / 时码换算。分别作为独立工具发布。

理由：兼顾统一入口、视觉创作与音乐 / 视频场景；前两组可继续使用现有 Python + Qt，计算工具也不需要媒体引擎。

### 0.4 候选：文件整理与交付

先做有预览和撤销记录的批量重命名，再建立可取消的图片导出队列。项目规格卡从名称、目录和可选字段起步，供命名与输出工具显式取用。暂不要求建立完整素材库。

### 0.5 候选：媒体辅助

先读取音视频元信息、抽帧与检查用户要求的规格，再扩展代理、音轨提取和响度分析。引擎可用性、分发方案、许可与安装包体积需要在集成时核实。

这些版本号是规划分组，不是发布日期承诺。用户反馈可能调整范围；macOS 真机验证与现有问题修复贯穿各阶段。

## 可以形成的三条完整流程

- **设计**：打开参考图 → 对照字体 → 计算输出尺寸 → 多尺寸导出 → 统一命名。
- **视频**：查看素材规格 → 记录项目帧率 → 抽取分镜帧 → 生成联系表 → 整理交付文件。
- **音乐**：Tap Tempo → 计算段落与延迟时长 → 记录工程规格 → 检查分轨信息 → 统一命名。

当前只实现其中的字体、尺寸、BPM 音符换算、色彩与保存辅助；流程中的其他步骤为规划。

## 共享架构

继续使用 **Python + PySide6**，按目标系统分别构建 Windows 和 macOS 包。

- **应用外壳**：导航、工具搜索、收藏、最近使用、窗口管理；首次打开不要求建项目。
- **内置工具注册表**：稳定 ID、名称、分类、关键词、页面工厂、输入 / 输出能力。已有页面逐个接入。
- **项目与资源服务**：规格字段、目录入口、托管参考图、资源引用；无需依赖 Photoshop、Cubase 等宿主的工程格式。
- **任务与文件服务**：预览、冲突检查、独立输出、进度、取消、失败重试、操作记录；供图片和媒体处理共享。
- **平台适配层**：前台窗口、输入空闲、快捷键、屏幕能力与系统权限；保留 Ctrl / Command 和用户自定义规则。
- **具体工具模块**：参考、文字、色彩、换算、文件、媒体、创作保护，各自保留领域逻辑与测试。

现有代码以 `ui.py` 为主窗口，`design_ui.py` 提供工具页面，`design_core.py` 提供配色与计算，PaletteModel 共享主面板和悬浮状态。工具注册表、项目服务、资源服务和通用任务队列均尚未实现。

完整交互、验收和边界见 [下一阶段方案](NEXT_STAGE_SPEC.md)。
