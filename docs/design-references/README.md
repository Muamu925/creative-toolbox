# 设计参考

通过 getdesign 0.6.25 添加 Figma、Notion 和 Apple。官方 npm 包通过 SHA-512 校验，再以 npx 的离线包方式分别写入子目录；最初的在线 Figma 命令也完成了，重复文件已合并。项目根 DESIGN.md 保留为自身规范。

- [Figma](figma/DESIGN.md)：内容与工具的层级。
- [Notion](notion/DESIGN.md)：克制的界面、清楚的文字层级。
- [Apple](apple/DESIGN.md)：控制层材质、留白与边界。

这些是 VoltAgent/awesome-design-md 的第三方设计分析，不是品牌官方组件或字体。参考主要描述营销页面，不能直接作为桌面工具的交互规范；本项目的动效时长和文案由实际任务决定。
