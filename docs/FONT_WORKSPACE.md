# 字体工作台使用说明

0.3.0 已实现：本机字体列表、名称 / 别名 / 标签搜索、文字系统与等宽筛选、分组、收藏、标签、备注、2–4 栏对照以及整理备份。

## 选字与整理

1. 打开左侧「字体工作台」，输入项目文案和字号。列表按字体家族展示，样式数量显示在名称旁。
2. 搜索名称、别名或标签；用空格组合条件。可以叠加文字系统与等宽筛选，左侧选择全部、收藏、当前不可用或自定义分组。
3. 点击「新建分组」，例如“音乐节海报”。按 Windows Ctrl / macOS Command 多选字体，Shift 连选，在下方操作列表选择「加入分组…」，再点「执行」。
4. 下方还可以收藏、取消收藏、添加 / 移除一个标签，或从当前分组移出。删除分组不影响字体文件、其他分组、收藏或备注。
5. 单选字体后打开「详情 / 备注」，保存别名、来源链接和用途 / 授权记录。链接只记录为文本，软件不据此判断授权。

## 对照效果

选中 2–4 款当前可用字体后点击「对照所选」。也可直接进入「多栏对照」选择字体和真实可用的样式。每栏可复制字体家族名称。小窗口下可滚动查看对照区。

列表样张是单行展示；完整多行文案在对照区查看。文字系统是粗粒度筛选，不保证覆盖所有文字；系统可能对缺字使用其他字体。当前没有字形覆盖检测或自动风格分类。

## 本地保存与备份

字体整理文件位于应用数据目录的 fonts.json，与保存规则、配色库分离。分组、标签、收藏和备注在操作成功后保存；预览文案（最多 2000 字）与字号会保存，便于下次继续。

「导出备份」包含这些整理信息，不包含字体二进制。导入前显示记录数、分组数和当前不可用字体数。完全相同的家族名称合并；不同名称不自动映射。收藏和标签合并，已有非空备注 / 别名 / 来源发生冲突时保留本机值并列出冲突，原备份不变。分组 ID 冲突且名称不同会创建独立分组；同名新组自动加导入后缀。导入不覆盖当前预览文案和字号。

刷新字体时，已经不可用的字体仍保留整理信息；可从「当前不可用」查看。跨系统或语言变化可能导致家族名称不同，本版不提供自动匹配。

损坏的字体整理文件会保留，页面进入只读状态。请先备份原文件，再修复或移出 fonts.json 后重启；不要将空示例库当作原库覆盖导出。

限制：最多 200 个组、10000 条字体整理记录、每字体 50 个标签；单次备份最大 8 MB。目录扫描、未安装字体预览、安装 / 卸载、自动激活及智能分组继续规划。

## 开发验证

66 项项目测试通过，其中字体专项覆盖多组引用、重启、导入合并、损坏数据、保存失败、组合筛选、多选操作和对照同步。Windows 已用本机 2056 个家族检查原生页面和小窗口；这不是所有字体格式或语言的完整兼容性保证。macOS 仍需真机检查。
