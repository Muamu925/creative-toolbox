# 创作工具箱 0.6.0 · 有序整理，随时找到帮助

## 帮助就在工具旁
新增离线帮助中心：首次使用、功能介绍、常见问题搜索，并可直接打开对应工具。
侧栏「帮助」、首页上手指南、顶部「本页帮助」和 F1 均可进入，无需联网。

## 连接参考与配色
- 图片可加入多个集合，按集合与关键词共同查找。移除集合保留图片。
- 在集合内导入 / 粘贴图片，任务完成后自动归类。
- 从素材图提取近似主色，预览命名后存成色板；图片与色板可双向跳转。
- 缺失来源或切换素材库时明确提示，已有色号仍可使用。

## 优化与兼容
- 保存已整理图片后立即更新待整理筛选。
- 紧凑窗口收紧预览区域，把来源入口放到色板标题下。
- 旧图片库升级前保留数据库副本；旧 ZIP 可恢复并升级。
- 备份导出与恢复共用索引大小限制，超限或失败保留原数据和已有备份。
