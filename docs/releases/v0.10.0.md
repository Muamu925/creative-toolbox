# 0.10.0 · Mac 工作台与项目资料预览版

本次包含 Mac 工作台重制和正式化界面文案，并继续原定 C 阶段：从个人资料库进入项目组织与交付准备。

- Mac 原生菜单、Command 快捷键、快速打开、Dock 重新打开和窗口尺寸记忆。
- 界面标签、操作提示与空状态统一采用正式表述。
- 项目规格卡支持平面 / UI、视频、音乐、三维类型，仅名称必填。
- 关联图片稳定编号，保存项目独立配色和字体候选，支持色号复制与配色编辑。
- 项目复制、归档与恢复；未保存修改保护和修订冲突检查。
- 导出 Markdown 项目说明，包含规格、交付要求与资源清单。
- 统一资料搜索增加项目，完整备份纳入项目数据库并保留图片引用。
- 图片移入回收站前提示已保存的项目引用。

新增 `projects.sqlite3`，旧图片、字体与色板格式保持不变。项目配色与字体候选为独立副本；实时共享引用、批量图片输出和宿主工程归档仍待后续实现。[项目使用说明](https://github.com/Muamu925/creative-toolbox/blob/v0.10.0/docs/PROJECTS.md)

验证：183 项测试，其中 181 项通过、2 项 Windows 专用测试在 Mac 跳过。项目规格与资源页完成 1180×800、1020×720 原生窗口检查，并验证示例说明导出。

下载：Windows x64 使用 ZIP，完整解压后启动 `CreativeToolbox/CreativeToolbox.exe`；macOS 13+ 使用与芯片架构对应的 DMG，将应用拖入 Applications。发布附件由 GitHub Actions 分别测试与构建，并附 SHA256SUMS.txt。

安装包未经过代码签名或 Apple 公证。Mac 界面已在 Apple Silicon 本机检查，真实创作软件的保存交互仍需使用可丢弃文件验证。完整备份新增项目数据库，含项目的备份请使用 0.10.0 或更新版本恢复。
