# Creative Toolbox 0.4.0 · 首页与工具入口

这个版本整理了综合工具箱的使用入口：启动后进入首页，从常用与最近使用继续工作；在工具目录中搜索、收藏，再打开具体工具。

- 首页、资源库、工具三类主入口；创作保护与设置在侧栏下方。
- 工具搜索支持字体、毫米、PPI、BPM、提色、保存等关键词。
- 收藏与最近使用保存在本机，重启后保留。
- 字体、配色、换算按需创建，重复打开复用页面与状态。
- 保存系统适配加载失败时，其他本地工具仍可使用。
- 创作保护内部集中显示状态、应用规则与活动记录。
- 沿用已有字体、配色和保存规则数据，新增工作台偏好独立保存。

资源库目前仅集中字体与配色入口。图片收集、跨资源关联、项目管理和完整素材库备份将在后续版本开发。

下载 Windows ZIP 后完整解压，打开 CreativeToolbox/CreativeToolbox.exe，保留整个文件夹；macOS 选择对应架构的 DMG。

安装包未签名或公证，macOS 仍需真机安装和权限验收。自动保存每次启动从观察模式开始；发送快捷键不代表确认文件已保存。请先用可丢弃文件试用。
