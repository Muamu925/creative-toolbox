创作工具箱 0.3.0：新增字体工作台，继续完善面向设计、剪辑与音乐创作的桌面工具集合。

Creative Toolbox 0.3.0 adds a font workspace alongside the existing creative utilities.

### 字体工作台 / Font workspace
- 搜索本机字体、别名和标签，按文字系统与等宽筛选。 / Search installed font families, aliases and tags; filter by writing system and monospace.
- 项目分组、多选标签、收藏、备注；同一字体可加入多个组。 / Groups, batch tagging, favorites and notes; fonts may belong to multiple groups.
- 自定义预览文案、字号、2–4 栏实际样式对照与字体名称复制。 / Custom samples and size, 2–4 font comparisons with available styles, and name copying.
- 本地原子保存、JSON 整理备份与合并；不可用字体保留整理信息。 / Atomic metadata storage, JSON backup/merge, and retained metadata for unavailable fonts.

[使用说明 / Usage guide (Chinese)](https://github.com/Muamu925/creative-toolbox/blob/main/docs/FONT_WORKSPACE.md)

### 下载 / Downloads
Windows x64：完整解压 ZIP 后运行 CreativeToolbox/CreativeToolbox.exe，无需 Python。

Windows x64: fully extract the ZIP and run the EXE; no Python installation required.

macOS：实验性 DMG，架构见文件名。已自动构建测试，仍需真机安装、权限与交互验证。安装包未签名或公证。

macOS: experimental DMG, architecture in the filename. Automated builds/tests do not replace real-device checks. Packages are unsigned and not notarized.

### 范围与验证 / Scope and validation
本版管理系统当前可用字体，不安装、卸载或激活字体。备份不含字体文件；按完整本机家族名称匹配，不自动推断跨平台别名。缺字可能由系统回退显示，预览不表示商用授权。

This version organizes system-available fonts without installing, uninstalling or activating them. Backups contain metadata only. Matching uses full local family names; cross-platform aliases are not inferred. Missing glyphs may fall back to other fonts; previews do not establish usage rights.

66 项项目测试通过；Windows 已检查本机 2056 个字体家族的原生界面及小窗口布局。现有智能保存仍默认观察模式，发送快捷键不等于确认文档保存成功。

66 project tests pass. Windows native UI was checked with 2056 local font families and compact windows. Smart Save still starts in observation mode; sending a shortcut does not confirm a successful save.
