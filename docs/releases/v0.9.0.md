# 0.9.0 · Mac 工作台重制预览

Mac 工作台采用紧凑侧栏、中性浅色界面与系统字体。图片、字体、色板、换算可以直接进入；首页展示真实收藏和最近打开的工具。

增加原生菜单栏、⌘K 快速打开、⌘F 页面搜索、⌘⇧F 资料搜索、⌘, 设置、窗口关闭后重新显示、窗口尺寸记忆和侧栏隐藏。Mac 新建规则的自定义快捷键默认为 Cmd+S。

创作保护未获得权限时，不再查询受保护的输入状态。截图与安全预览模式完全禁用系统输入监控。原有本地资料格式、按需加载、完整备份恢复、图片关联配色和字体对照均保留。

提供独立 Mac 开发启动器、Bundle 元数据与可拖入 Applications 的 DMG。该阶段改进随 0.10.0 一并发布；Apple Silicon / macOS 13+，未经过 Developer ID 签名或公证。

验证：164 项自动化测试（162 通过，2 项 Windows 测试跳过）；九个页面在两种尺寸下通过原生启动与截图检查。自动保存宿主兼容性、Intel 与其他系统版本仍待实机验证。[完整说明](../MACOS.md)
