# 创作工具箱 0.7.0 · 冷白与钴蓝

统一整个工具箱的视觉语言，覆盖首页、图片素材、字体、配色、创作换算、智能保存、设置与帮助。

- 冷白背景、石墨文字与钴蓝主操作；统一圆角、输入、菜单、选中和键盘焦点。
- 轻量玻璃风格导航与顶部栏，内容区保持清晰的不透明表面。
- 设置新增「减少透明效果」，立即生效并在本机保存。
- 首页操作更紧凑，工具入口不再重复使用高强调主按钮。
- 全新托盘与创作面板图标，Windows ICO、macOS ICNS 和应用内图标统一；导航采用 Phosphor 线性图标。
- 更新实际窗口截图和完整设计规范，保留资源原色与真实字体样张。

130 项自动化测试通过，包括外观持久化、损坏文件保护、写入失败、文字对比度、图标加载与紧凑控件检查。Windows 在 1180×800 与 1020×720 两种逻辑尺寸进行原生截图审阅，独立程序启动、内置视觉资源和 ZIP 完整性检查通过。

玻璃为跨平台绘制的近似效果，不是原生 Liquid Glass，不读取或模糊桌面。图片、字体、色板、保存规则的格式不因本次视觉升级改变。

Windows：完整解压 ZIP 后运行 CreativeToolbox/CreativeToolbox.exe。
macOS：实验性未签名 / 未公证 DMG，仍需真机交互验证。

每次启动继续从观察模式开始；发送保存快捷键不代表已经确认文件写入磁盘。
