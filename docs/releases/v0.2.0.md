### 已知边界 / Preview limitations
软件界面目前以中文为主；Windows 已做本地启动检查。macOS 已通过自动构建与测试，尚未完成真机安装、权限和创作软件交互验收。安装包未签名或公证。

The interface is currently primarily Chinese. Windows has been checked locally; macOS has automated build/test coverage but still needs real-device installation, permission and host-app checks. Packages are unsigned and not notarized.

智能保存默认观察模式。发送保存快捷键不代表确认保存成功；录音、MIDI、渲染和首次保存无法通用识别，请先用可丢弃文件测试。颜色工具面向不透明 sRGB，提色为近似值。

Smart Save starts in observation mode. Sending a shortcut does not confirm a successful save; recording, MIDI, rendering and first-save dialogs cannot be detected universally. Test with disposable files. Color tools target opaque sRGB and image colors are approximate.
