# 资源搜索与完整备份（0.8.0）

## 搜索个人资料

打开侧栏「资源库」，输入关键词，可按图片、色板、字体筛选。双击结果、按回车或点「打开选中资料」回到原工具。清空搜索后显示资源工具入口。

- 图片：名称、标签、来源、备注；不包含回收站。
- 色板：名称、颜色名称、HEX、来源图片名称；仅搜索已保存色板。
- 字体：已保存整理记录的家族名、别名、分组、标签、备注、来源；没有整理记录的系统字体请在字体库中查找。

关键词以空格分隔，要求同时匹配；大小写不敏感。后台查询，每类最多显示 100 条并显示总数。部分模块损坏时显示具体提示，其余模块继续搜索；不会创建示例资料来替代损坏数据。

选择色板时会核对搜索时的内容指纹。重排后可重新定位；修改后不能确定原条目时提示重新搜索，不按过期序号打开其他色板。字体即使在当前电脑不可用也保留整理记录。

## 完整备份

点击「完整备份」，选择数据目录以外的位置，保存 `.ctbackup` 文件。

包含当前图片库原件、索引、集合、回收站，以及现有的 palettes.json、fonts.json、settings.json、workspace.json、appearance.json。保留图片库身份和色板来源关系。字体文件、未保存编辑、活动日志、缓存、旧恢复目录不包含在内。

备份前处理素材未保存整理并保存字体预览偏好。正在运行的素材任务需先完成。备份期间使用应用级模态窗口暂停编辑，关闭悬浮色板，阻止托盘重新打开编辑器或退出，切回观察模式。JSON 读取已保存快照；SQLite 使用备份 API；不可变原件逐一校验。失败或取消不替换已有备份文件。

备份同时需要临时磁盘空间；大资料库的处理时间和空间消耗取决于图片数量与体积。图片库原有 5 GiB 原件上限保持不变。本版不提供云同步、增量备份或自动定时备份。

## 恢复和切换

选择「恢复备份」，打开 `.ctbackup`。恢复先检查清单、路径、大小、摘要和各模块格式，再校验图片数据库、原件与集合并重建预览。只写入新目录，不覆盖当前资料。

成功后可选择切换。切换会保存位置记录并退出工具箱；重新打开使用恢复资料，仍为观察模式。默认快捷键风格继续按运行平台解析，自定义快捷键和按应用规则需自行确认。跨设备字体按完整家族名匹配，字体文件需自行安装。

取消切换时，恢复副本保留，提示目录位置。旧资料继续保留，不自动清理。需要重新选择某个保留副本时可再次从原备份恢复，或使用 `--data-dir` 指定副本目录启动。

要回到最初资料：退出工具箱，备份最初的数据目录，将其中 `active-workspace.json` 改名保留后重新打开。该文件记录当前恢复目录，保留后可用于返回。不要在运行时移动目录。

图片库原来的 ZIP 备份仍然可用，但只包含图片模块；它与完整 `.ctbackup` 不是同一格式。
