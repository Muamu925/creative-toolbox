# Creative Toolbox icon

Master: toolbox-master.png. Generated with the built-in image generation tool, then recolored by the same tool to the user-selected cobalt blue. ICO/ICNS/PNG conversion only resizes and changes encoding; no code-generated visual elements were added to the master.

Final generation direction: an open cobalt-blue (#245CDB) tray holding two translucent creative panels, on a smooth frosted porcelain-white rounded-square tile, cool silver and pale ice-blue lighting, a bold silhouette, transparent surroundings, no text and no third-party brand marks. This represents a general creative toolbox rather than a single color utility.

Rebuild formats from the committed master using tools/prepare_brand_assets.py. The native Windows/macOS shell controls the ultimate small-size rendering and icon caching.
